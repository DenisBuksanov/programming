# Простейший переводчик на C

Консольная программа на языке Си, которая переводит слова в текстовом файле по заданному пользователем словарю. Программа создана с упором на бережную работу с памятью и сохранение исходного форматирования текста.

## ✨ Основные особенности

* **Полное сохранение разметки:** Все пробелы, точки, запятые, многоточия и переносы строк остаются строго на своих местах. Текст не превращается в сплошную кашу.
* **Поддержка многозначности:** Если у слова в словаре указано несколько переводов (до 5 штук), программа выведет их все через косую черту (например: `яблоко/ранет`).
* **Умная работа с регистром:** Если слово в исходном тексте начиналось с большой буквы (`Apple` / `Город`), то и его перевод автоматически запишется с большой буквы (`Яблоко` / `City`). Работает и для латиницы, и для кириллицы.
* **Динамический словарь:** Программа не имеет жестких ограничений на размер словаря. Место в оперативной памяти выделяется на ходу и удваивается по мере необходимости.
* **Поддержка UTF-8:** Корректно обрабатывает двухбайтовые русские буквы в современных системах (macOS, Linux).

## 🛠 Как устроен словарь

Файл словаря должен быть текстовым, где каждая строка содержит оригинал слова (маленькими буквами) и варианты его перевода через пробел или табуляцию:

```text
apple яблоко ранет
car машина автомобиль авто
run бежать
город city town
```

## 🚀 Инструкция по запуску
1. Сборка проекта
Для сборки программы используйте утилиту make (если в проекте есть Makefile) или скомпилируйте вручную через gcc:

```Bash
gcc rgr.c -o translator
```

2. Запуск программы
Программа принимает ровно 3 аргумента командной строки: путь к исходному тексту, путь к словарю и путь к файлу, куда сохранить результат.

```Bash
./translator текст.txt словарь.txt результат.txt
```

## Пример работы
Исходный текст ```(текст.txt)```:

Apple, a big car, and a... Run! Этот красивый Город прекрасен.

Результат ```(результат.txt)```:

Яблоко/ранет, a big машина/автомобиль/авто, and a... Бежать! Этот красивый city/town прекрасен.
